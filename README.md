# My Love, Shreeya (Shreio)

A pink love site built for Shreeya and Naeem.

## How to Auto-Sort Photos into the Gallery & Card Portraits

1. **Card Portraits**:
   - Paste Shreeya's main profile picture into `gallery/her-portrait/`.
   - Paste Naeem's main profile picture into `gallery/me-portrait/`.
2. **Gallery Photos**:
   - Paste photos of Naeem into `gallery/me/`.
   - Paste photos of Shreeya into `gallery/her/`.
   - Paste photos of both together into `gallery/us/`.
3. **Run the Sync Command**:
   - In terminal:
     ```bash
     npm run sync
     ```
   - Or on Windows, simply double-click `sync.bat`.

The photos and main card portraits will automatically sort and load into the website!

## Adding Audio Tracks

- **Favourite Songs**: Drop `.mp3` files into `audio/music/` (e.g. `sweater-weather.mp3`, `steal-my-girl.mp3`, `lovebomb.mp3`, `drivers-license.mp3`, `siren-sounds.mp3`).
- **Secret First Kiss Song**: Drop your secret `.mp3` file into `audio/secret/` (e.g. `first-kiss-secret.mp3`).

## Shreio Forever
Open `index.html` in any web browser to enjoy!
